# 跳跳月曆

跟小青蛙「跳跳」一起看月曆的小遊戲。月曆釘在軟木板上，貼著生日派對、放風箏、踢足球等活動貼紙，小朋友要找出那天是星期幾、第幾個星期幾是幾號，還要跟著跳跳在月曆上跳來跳去數日子。

**整個遊戲只有一個 `index.html` 檔案，不用網路、不用安裝、不用註冊，也不會蒐集任何個人資料。** 特別適合網路不穩或設備有限的偏鄉教室。

## 線上使用

👉 https://je5577iee.github.io/hop-calendar/

## 離線使用（沒有網路的教室）

1. 在有網路的地方下載本專案的 `index.html`（點進檔案 → 右上角「Download raw file」）
2. 用隨身碟複製到教室的電腦或平板
3. 點兩下用瀏覽器打開就能玩，完全不需要網路

## 玩法

選好難度後按「開始」，一回 10 題。月曆用的是**今年真的月份**，每 3 題換一個月，每個月貼著 5 張活動貼紙。

### 四種題目

| 題目 | 例子 | 怎麼回答 |
|---|---|---|
| 找星期 | 「放風箏」那天是星期幾？ | 點星期按鈕 |
| 第幾個星期幾 | 這個月第 3 個星期日是幾號？ | 直接點月曆上的日期 |
| 跳跳跳幾天 | 跳跳在「生日派對」那天，往前跳 9 天，會跳到星期幾？ | 點星期按鈕或點日期 |
| 還要幾天 | 從「生日派對」到「放風箏」，還要過幾天？ | 四選一 |

「往前跳」是日期變大，「往回跳」是日期變小。

### 三種難度

| 難度 | 內容 |
|---|---|
| 簡單 | 找星期、找第一個星期幾、往前跳 1～3 天 |
| 進階 | 第幾個星期幾、跳更多天、算還要幾天 |
| 困難 | 往前跳也往回跳、跳得更遠、最後一個星期幾 |

## 提示會在月曆上演給小朋友看

- **答錯第一次會出現提示，可以再試一次**；第二次才答對算一半
- 找星期：那一格會圈起來，整條星期亮起來，往上看就知道
- 第幾個星期幾：那一直排亮起來，旁邊標上 1、2、3 幫忙數
- 跳超過 7 天：小秘訣「往前跳 7 天，就是正下方那一格」
- 跨到另一個星期：「星期六的下一天是星期日，所以要換到下一排的最前面喔！」
- 第二次還答錯，**跳跳會真的在月曆上一格一格跳**，邊跳邊標上數字；跳到星期六會從右邊跳出去，再從下一排的左邊跳進來
- 答錯時不會出現傷心或責備的畫面，只有鼓勵的話

## 其他功能

- 首頁的月曆是**這個月**，今天那一格會被圈起來
- 星期日紅字、星期六藍字，跟一般月曆一樣
- **注音開關**：首頁可以打開注音，採用國語課本的直式注音
- **音效開關**：音效由瀏覽器即時產生，不需要音檔
- 每個難度的最佳成績會以星星顯示（只存在這台裝置）
- 支援電腦、平板、手機；系統若開啟「減少動態效果」，會自動關閉跳躍動畫

## 適用對象與教學建議

- **適用**：國小學生認識月曆、星期、日期，也適合課後輔導、補救教學
- **課堂示範**：投影首頁的月曆，讓學生說出今天是幾月幾日星期幾
- **生活連結**：玩完後請學生在家裡的月曆上找自己的生日是星期幾
- **觀察規律**：引導學生發現「同一直排往下一格就是加 7 天」

## 注意事項

- 最佳成績只存在**那台裝置的瀏覽器**裡，換裝置或清除瀏覽器資料就會消失
- 首頁的「這個月」和「今天」是看裝置的日期；如果電腦的日期設錯了，首頁的月曆也會跟著錯，遊戲題目則不受影響
- 注音經過人工檢查，若發現讀音有誤，歡迎提出 Issue 告訴我們
